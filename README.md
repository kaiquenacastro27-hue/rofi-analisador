# ROFI · Analisador

Página única (`index.html`) que lê o ROFI.xlsx no navegador e monta as análises de roteirização:
visão geral, semana × semana com ofensores, SPR (subir ou baixar), hubs, modal e vans, órfãos,
qualidade do preenchimento, analistas e suporte.

- O arquivo é processado no navegador de quem abre a página; nada é enviado a servidor.
- Publicado pelo GitHub Pages a partir da branch `gh-pages`, no endereço https://rofi.routingtools.com.br
